## Stephen Tracy

I'm a generalist by choice. My best work begins with taking ownership of a problem that's complex and unfamiliar. I come to understand it, give it structure where none existed, and solve it.

I build apps, workflows and tools, usually to answer a question I have or to make my own work run better. Strategy and analytics, zero-to-one operations, product and web building, data science, AI systems.

Most of that work is private, or a client's. What is public sits below.

**[claude-os](https://github.com/tracsj/claude-os)** — six skills for building and maintaining a Claude Code setup, cut from the system I run across more than a dozen projects.

**[match-predictor](https://github.com/tracsj/match-predictor)** — football forecasting, measured against closing betting odds. The pre-registered rule lost money, and the write-up says so.

**[stephentracy-site.vercel.app](https://stephentracy-site.vercel.app/)** — what I have built and operated, with the numbers attached.

Older repositories here are coursework from a data science master's, kept for the record.
